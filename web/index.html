本地照片目录只能在服务器上修改，这里仅作说明：

  1. 编辑项目目录里的 .env，把 PHOTOS_DIR 改成照片所在的文件夹。
  2. 在项目目录执行 docker compose up -d，容器会重新挂载新目录。

目录以只读方式挂载，子文件夹会自动成为相册。支持 jpg、jpeg、png、webp、gif；名字以 . 开头的文件和文件夹会跳过。

对象存储

支持兼容 Amazon S3 接口的服务，例如 AWS S3、Cloudflare R2、MinIO、Backblaze B2、Wasabi、阿里云 OSS、腾讯云 COS。可以添加多个，照片会和本地图库合并展示；同名文件夹合并为同一个相册。只读取图片，不会上传、修改或删除存储里的文件。
