# 按相册批量分享设计

2026-10-13 19:18:49 CST。基线为 netcup 与本地仓库的 `5ff9169`。本轮 Q1–Q16 已由用户逐项确认；用户已确认最终理解 Q17，并授权实现、验收、生产部署、推送仓库及清理；已完成实现与隔离验收，生产部署待完成。

## 已确认的行为

1. 选择一本或多本相册，对其中每张原图批量开启独立的分享链接；相册浏览页面仍需登录。
2. 同时提供按相册批量停止分享。
3. 只处理本次操作时相册里已有的图片，以后新增图片需要再次主动开启。
4. 相册列表提供勾选及批量开启、停止；单本相册顶部也提供开启、停止。
5. 沿用当前相册范围：完整相对目录内的直接照片，不递归包括子目录；页面合并展示的不同存储来源一起处理。
6. 批量停止覆盖选定相册内的全部已分享图片，包括以前逐张手动开启的分享。
7. 批量开启后显示结果，并提供「复制全部分享链接」；用户点击后复制，每行一个原图地址。
8. 单张失败继续其余图片，保留成功结果，显示成功、失败数量和失败原因，并允许只重试失败项。
9. 开始后关闭或离开页面仍继续处理，重新打开相册可查看进度和结果。
10. 执行前展示所选相册、图片总数和预计开启或停止数量，由用户核对后点击执行。
11. 全选只覆盖当前筛选显示的相册；改变筛选条件清空勾选。
12. 相册列表显示未分享、部分已分享、全部已分享及已分享数量。
13. 应用重启保留已完成结果，将未完成任务标为已中断；由用户主动重试剩余项，不自动继续执行。
14. 同时只运行一个批量任务；单图操作仍可用，较晚的单图开启或停止优先，旧批量任务不得覆盖。
15. 提供「取消剩余处理」，已完成结果保留；撤回已经开启的分享使用批量停止分享。
16. 任务完成、取消或中断后的进度及结果保留 48 小时，记录过期不影响图片分享的有效期。

## 用户操作流程

### 选择与核对

- 在相册列表勾选一本或多本，或在单本相册顶部直接选择开启或停止。
- 全选只覆盖当前筛选结果，更换筛选清空勾选；显示已选数量。
- 执行前列出相册、图片总数、已分享数及预计变更数。用户点击执行时使用这次核对的范围，后续新增图片不加入。
- 范围包含所选相册在各存储来源中合并展示的全部直接图片；不因当前页面分页、已加载数量或「只看已分享」显示条件漏掉目标原图。

### 处理与恢复

- 开启逐张核对原图，已有且仍对应同一原图的分享复用原链接；停止覆盖当前范围内已开启的许可。
- 显示总数、已处理数、成功与失败数量，以及逐张失败原因。成功项不因其他图片失败而回滚。
- 关闭页面不取消执行。重新进入相册可查询当前任务及尚在保留期内的结果。
- 已有批量任务运行时，新批量任务需等待当前任务完成或取消；不排队自动提交新的分享意图。
- 取消以服务器核对后的实际完成结果为准，已完成项保留，剩余处理结束；不把可能已提交的项错误显示成未执行。
- 重启后已完成许可及结果保留，未完成任务显示已中断，剩余项需用户主动重试。
- 重试仅限该次失败或未完成的目标，重新核对原图和分享修改事实；已换图、移动、删除或被较新的单图操作改变的项不能由旧任务覆盖，提示重新核对范围。

### 结果与链接

- 批量开启的结果提供用户主动点击的「复制全部分享链接」，每行一个地址，覆盖本次范围中成功开启及复用的分享。
- 复制时核对许可是否仍对应本次原图与分享身份，不复制已经停止或失效的旧地址；不把失败项、后来新增图片或后来重新开启的另一份许可混入旧任务结果。
- 浏览器不允许写剪贴板时显示可手动复制的地址，沿用单图分享的真实结果提示。
- 相册列表显示未分享、部分已分享、全部已分享及已分享数量；批量和单图变化后更新显示与「只看已分享」结果。
- 终止后的任务记录保留 48 小时。过期清理只删任务记录，图片仍按原分享规则有效，仍可在大图中逐张管理。

## 拟采用的实现边界

- 沿用 Go、Next.js 静态前端、SQLite、单容器、单应用进程。批量执行发生在应用进程内，不依赖浏览器存活，不增加外部队列或常驻执行服务。
- SQLite 保存任务身份、所选相册及固定图片范围、原图版本、分享修改代次、逐项进度与结果。准备范围与正式执行明确区分，重复提交同一任务不能创建第二份任务或重新执行已完成项。
- 复用现有原图核对、来源读取及分享许可规则；逐项分享变更与该项完成结果在同一事务中保存，避免重启或响应丢失时猜测某张图是否已执行。
- 活动任务保持一个；原图读取沿用现有资源限制。没有任务时不进行原图读取或持续轮询。页面只在任务处理中轮询进度。
- 启动时将未完成任务标为中断；取消与提交之间协调，不能让已确认取消的任务继续提交新的许可。终止记录按 48 小时清理，复制输出再次核对当前许可。
- 管理和结果查询沿用登录保护，写操作沿用同源门禁。公开入口仍只返回选定原图，普通相册、缩略图及原图查看入口仍需登录。

## 现有实现事实

- 单图分享的原图链接、停止后失效、重新开启换地址，以及替换、移动、删除后的失效规则见 `image-hosting-plan.md`。
- 开启分享要完整读取并核对原图内容，不是只更新一个状态。已有分享再次开启也会核对原图；有效的同一次分享复用原链接。
- 相册列表目前没有勾选功能；整理相册页面已有勾选与全选交互，但其批量保存仅处理人物资料。
- 现有上传和扫描可在进程内继续处理，但没有可在应用重启后续跑的批量分享执行器；已完成的单图分享许可存于 SQLite，重启后仍保留。
